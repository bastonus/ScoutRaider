# modules

## Overview
Collection of cryptographic and cryptographic-cipher puzzle modules for legacy raid generation.

## Subdirectories & Boundaries
- avocat: [avocat](./avocat/README.md) - Legacy Avocat (A=K) Caesar cipher encoding module for scout raid puzzles.
- carte_ign: [carte_ign](./carte_ign/README.md) - Legacy IGN topographic map snippet extraction and clipping module.
- carte_simple: [carte_simple](./carte_simple/README.md) - Legacy simplified schematic map generator for navigation stages.
- cassis: [cassis](./cassis/README.md) - Legacy Cassis (K=6) cipher encoding module for scout raid puzzles.
- drapeaux: [drapeaux](./drapeaux/README.md) - Legacy semaphore / flag signal puzzle encoding module.
- gilwell: [gilwell](./gilwell/README.md) - Legacy Gilwell woodcraft navigation grid encoding module.
- maritime: [maritime](./maritime/README.md) - Legacy International Maritime Signal flags puzzle encoding module.
- morse: [morse](./morse/README.md) - Legacy Morse code audio and visual encoding module.
- polybe: [polybe](./polybe/README.md) - Legacy Polybius square cipher puzzle encoding module.
- templier: [templier](./templier/README.md) - Legacy Templar cross substitution cipher puzzle encoding module.
- texte_clair: [texte_clair](./texte_clair/README.md) - Legacy plaintext instruction formatting module with typographic layout.
- vigenere: [vigenere](./vigenere/README.md) - Legacy Vigenere polyalphabetic cipher puzzle encoding module.
