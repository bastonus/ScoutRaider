# Module: routing_direct

## Rôle
Moteur local 100% hors-ligne calculant un segment direct entre deux balises géographiques (vol d'oiseau).
Essentiel pour les épreuves d'orientation scoutes (visées azimutales, marche au cap, traversée de forêt sans sentier).

## Spécification Hub v2
- **Resource Type**: `routing_engine`
- **Hors-ligne**: Oui (100% autonome)
