# Module: routing_brouter

## Rôle
Moteur de calcul de tracés pédestres et de randonnée basé sur BRouter.
Spécialisé dans l'identification des sentiers forestiers, chemins creux, GR et PR tout en évitant les routes carrossables.

## Spécification Hub v2
- **Resource Type**: `routing_engine`
- **Profiles supportés**: `hiking`, `trekking`, `pedestrian`, `safety`
- **Altitude**: Oui (ascendances et profils de pente)
