# Module: routing_valhalla_ign

## Rôle
Moteur de routage s'appuyant sur l'infrastructure souveraine de la Géoplateforme IGN (Valhalla / BD TOPO).
Garantit la conformité avec la cartographie topographique IGN au 1:25 000.

## Spécification Hub v2
- **Resource Type**: `routing_engine`
- **Profiles supportés**: `pedestrian`, `hiking`
- **Couverture**: France métropolitaine et DROM-COM
