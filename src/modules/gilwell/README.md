# gilwell

## Overview
Gilwell woodcraft puzzle module package integrating logic and React UI components.

## Interface
- `[index.ts] function createGilwellConfig()`
- `[index.ts] const GILWELL_MODULE_METADATA`
- `[index.ts] const VERSION`

### Subdirectories
- [components](./components/README.md) - React components for the interactive Gilwell grid editor and spreadsheet inspection.
- [logic](./logic/README.md) - Core computation engine, calculation models, and export logic for Gilwell navigation puzzles.

## Invariants
- None

## Side Effects
- None

## Verification
- Run: `npm run build`
