# Module: loader_geojson

## Rôle
Module d'importation et d'extraction de géométries vectorielles GeoJSON et FeatureCollections.
Reconnaît les géométries de type `LineString` (itinéraires), `Point` (balises/waypoints), et `MultiLineString`.

## Spécification Hub v2
- **Resource Type**: `path_provider`
- **Formats supportés**: `.geojson`, `.json`
- **Compatibilité SIG**: QGIS, Leaflet, Mapbox, Overpass OSM
