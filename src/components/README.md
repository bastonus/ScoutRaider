# components

## Overview
React UI component library structured into layout, map canvas, panels, and textual editor.

## Subdirectories & Boundaries
- layout: [layout](./layout/README.md) - Application shell layout components: window menu bar, tabs, command palette, and sidebars.
- map: [map](./map/README.md) - Interactive map canvas components: Leaflet/OpenLayers layers, toolbar, overlays, and HUD.
- panels: [panels](./panels/README.md) - Sidebar panels and modals for route editing, layer management, exports, and cloud auth.
- textual: [textual](./textual/README.md) - Rich textual carnet editor components: inline block editors, slash commands, and markdown rendering.
