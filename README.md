## 📸 Démo — Ce que l'app peut faire

Trois captures d'écran illustrent le flux complet, du tracé à l'instruction générée :

### 1. 🗺️ Génération d'itinéraire & azimuts
![Génération d'itinéraire et calculs d'azimuts](./assets/demo/generatepathinstructionsetcveryeasily.png)
*Tracer un itinéraire sur la carte → ScoutRaider calcule automatiquement les distances, azimuts et capes. C'est ici que le "vrai itinéraire" est relié par les routes/sentiers réels (routage BRouter).*

### 2. ✏️ Édition fine du chemin & ajustage
![Édition fine du chemin et ajustage d'azimuts](./assets/demo/editverycarfullygeneratedpathandazimut.png)
*Ajustage manuel du tracé et des azimuts. Vous gardez le contrôle total : déplacer un point, affiner un angle, changer la finesse de virage, tout se régénère instantanément.*

### 3. 📝 Instructions codifiées & Morse
![Instructions codifiées et chiffrage Morse](./assets/demo/editautogeneratedraidinstructionandusemoceandelse.png)
*Les instructions de navigation sont générées à partir des données réelles du terrain (points d'intérêt, noms de lieux), puis codifiées avec les modules choisis (Morse, Vigenère, Avocat, etc.). Le carnet s'édite librement après génération.*

## ✨ La magie de ScoutRaider

**Vous dessinez vos étapes. ScoutRaider fait le reste — puis vous gardez la main.**

1. **🖐️ Vous tracez vos étapes** sur la carte, comme sur une carte papier. Ajoutez, déplacez ou supprimez vos points : le terrain reste votre point de départ.
2. **🧭 Il calcule le vrai itinéraire** : ScoutRaider relie vos étapes par les routes et sentiers réels (routage BRouter), puis calcule pour chaque segment la distance exacte, l'azimut et le cap.
3. **✍️ Il trouve les mots justes** : à partir des **données réelles des lieux traversés** — points d'intérêt, noms de lieux, commerces, passages remarquables — il rédige des consignes de navigation vivantes et thématisées, ancrées dans le terrain plutôt que génériques.
4. **🪄 Vous éditez librement** : chaque étape, azimut, distance, texte et épreuve reste modifiable. Vous réécrivez, déplacez, changez le style de navigation — le carnet se régénère instantanément.

> **En résumé : vous pensez terrain, ScoutRaider rédige le carnet. Vous gardez toujours le dernier mot.**

## ⚠️ Avertissement de Sécurité

> **IMPORTANT — À lire avant toute utilisation terrain**
>
> Les **azimuts, métrages et instructions** générés par cette application sont calculés **algorithmiquement** et **peuvent contenir des erreurs**.
>
> **Avant d'envoyer des scouts sur le terrain, il est IMPÉRATIF de :**
> - ✅ **Vérifier manuellement** chaque azimut et distance sur une carte IGN papier
> - ✅ **Reconnaître l'itinéraire** sur le terrain avant le jour J
> - ✅ **Corriger les azimuts** si nécessaire avec l'outil d'édition
> - ✅ **Tester le carnet** en conditions réelles avec un chef avant distribution
> - ✅ **Prévoir un plan B** : points de ralliement, téléphone d'urgence
>
> L'équipe de développement **décline toute responsabilité** en cas d'erreur d'orientation liée aux données générées automatiquement.

## 🎯 Qu'est-ce que c'est ?

ScoutRaider est un outil conçu pour les **chefs et cheftaines scouts** (Guides et Scouts d'Europe) qui organisent des raids et des randonnées. Il permet de :

1. **Tracer un itinéraire** sur une carte interactive (fonds IGN, satellite).
2. **Découper automatiquement** le tracé en segments avec azimuts et métrages calculés.
3. **Encoder des épreuves** (Morse, Vigenère, azimut-distance, chiffres romains, etc.) le long du parcours.
4. **Générer des carnets PDF** prêts à imprimer : un carnet participant et un carnet solution pour les chefs.

## 📦 Installation & Accès

### Version Web (sans installation)

👉 **[scoutraider.silverhorse.fr](https://scoutraider.silverhorse.fr/)** — Ouvrez directement dans votre navigateur.

### Version Desktop

| Plateforme | Fichier | Instructions |
|---|---|---|
| 🪟 **Windows** | `ScoutRaider Setup.exe` | Double-cliquez pour installer |
| 🍎 **macOS** | `ScoutRaider.dmg` | Glissez l'app dans Applications |
| 🐧 **Linux** | `ScoutRaider.AppImage` | `chmod +x *.AppImage` puis lancez |

> **Note** : Les installeurs sont désormais générés automatiquement via GitHub Actions. Téléchargez la dernière version dans l'onglet **Releases**.

### Depuis les sources (Développeurs)

```bash
# 1. Cloner le dépôt
git clone https://github.com/bastonus/ScoutRaider.git
cd ScoutRaider

# 2. Installer les dépendances Node.js
npm install

# 3. Lancer en mode développement
npm run dev

# Lancer la fenêtre Electron (dans un autre terminal)
npm run electron
```
